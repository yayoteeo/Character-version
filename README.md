# SillyTavern 人设版本管理

这是一个纯前端 SillyTavern 扩展。它在“用户设定管理”的“重命名人设”按钮右侧添加版本入口，并在当前人设控制区下方展开人设版本管理区域。

## 功能

- 为同一个 SillyTavern 用户人设保存多个版本。
- 保存展示标题、描述、注入位置、深度、角色和关联世界书。
- 下拉框选择版本后立即应用，无需再点击“应用”。
- 支持覆盖更新、重命名和删除版本。
- 切换版本时保留原人设的角色/群组连接。
- 插件不会创建、复制、上传、删除或重命名 SillyTavern 人设和头像；所有版本都属于当前这一个人设。
- 未命名占位项不能保存或应用版本，必须先选择一个已经存在且已经命名的人设。
- 角色绑定板块支持一个版本绑定多个角色、一个角色绑定多个版本，并提供角色筛选与绑定版本预览。
- “绑定当前聊天”只保存插件自己的聊天映射，不会修改 SillyTavern 本体的角色锁定。
- 每个聊天只保存一个版本绑定；再次绑定会覆盖旧版本绑定。
- 进入已绑定聊天时，插件会等待酒馆本体完成用户人设切换，再应用聊天绑定的版本。
- 未绑定聊天不会因为插件而强制切换用户人设或应用版本。
- 开启“修改时自动保存”后，编辑描述、注入位置、深度或角色会即时更新已选版本；关闭后使用“更新版本”手动保存。
- 每个 user 人设库都提供“原始库”角色库，集中显示所有未绑定角色的人设版本；选中的版本可使用“锁定”按钮禁止编辑其人设内容。
- 数据保存在 SillyTavern 的服务端扩展设置中，不使用浏览器 localStorage；使用同一 SillyTavern 服务/账号的不同设备会读取同一份版本、绑定和锁定状态。

## 安装

将本目录复制到：

```text
SillyTavern/public/scripts/extensions/third-party/Character-version/
```

最终至少包含：

```text
Character-version/
├── manifest.json
├── index.js
└── style.css
```

重启 SillyTavern 或刷新页面后，在扩展管理中确认“人设版本管理”已启用。

## 使用

1. 打开“用户设定管理”，选择一个已有用户人设。
2. 点击“重命名人设”右侧的图层图标，展开版本管理区域。
3. 从版本框选择版本，插件会立即应用。
4. 在角色绑定板块中绑定当前角色；也可以在角色预览中选择已绑定角色并管理其版本。
5. 点击“绑定当前聊天”，插件会把当前聊天唯一绑定到该版本；再次绑定会覆盖旧绑定。
6. 进入已绑定聊天时，会自动切换父级 user 人设并应用绑定版本。
7. 点击“解除绑定”后，当前聊天恢复为不自动应用状态。
8. 开启“修改时自动保存”可即时更新版本；关闭时点击“更新版本”手动保存。
9. 选中“原始库”后点击锁定；锁定时描述、注入位置、深度、角色和关联世界书均不可编辑。

版本数据通过 SillyTavern 服务端同步。不同设备需连接同一 SillyTavern 服务并使用同一账号；切换设备后刷新页面即可加载最新数据。

删除版本只删除插件保存的快照，不会删除 SillyTavern 原始用户人设或头像。
