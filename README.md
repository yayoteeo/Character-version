# SillyTavern 人设版本管理

这是一个纯前端 SillyTavern 扩展。它在“用户设定管理”的“重命名人设”按钮右侧添加版本入口，并在当前人设控制区下方展开人设版本管理区域。

## 功能

- 为同一个 SillyTavern 用户人设保存多个版本。
- 保存展示标题、描述、注入位置、深度、角色和关联世界书。
- 下拉框选择版本后立即应用，无需再点击“应用”。
- 支持覆盖更新、重命名和删除版本。
- 切换版本时保留原人设的角色/群组连接。
- 插件不会创建、复制、上传、删除或重命名 SillyTavern 人设和头像；所有版本都属于当前这一个人设。
- 未命名占位项不能保存或应用版本，必须先选择一个已经存在且已经命名的人设。
- 版本可以绑定多个角色；在“角色范围”中点击“绑定当前角色”添加或解除绑定。
- 已绑定角色会显示为可点击标签；进入某个角色后，只显示通用版本和绑定到当前角色的版本。
- 一个版本可以绑定多个聊天，但每个聊天全局只能绑定一个版本；重新绑定会覆盖旧绑定。
- 版本面板上方提供角色父级搜索和选择：先搜索/选择当前 user 绑定过的 char，再在右侧版本框编辑该 char 的版本；另可查看未绑定角色的通用版本。
- 聊天绑定自动计入该版本的 char 绑定范围，因此“绑定过聊天”就等同于“绑定过该 char”。
- 进入已绑定聊天时自动切换到对应的基础用户人设并应用版本；未绑定聊天不会自动应用任何版本。
- 开启“修改时自动保存”后，编辑描述、注入位置、深度或角色会即时更新已选版本；关闭后使用“更新版本”手动保存。
- 数据保存在 SillyTavern 的扩展设置中，随用户设置正常保存。

## 安装

将本目录复制到：

```text
SillyTavern/public/scripts/extensions/third-party/Character-version/
```

最终至少包含：

```text
Character-version/
├── manifest.json
├── index.js
└── style.css
```

重启 SillyTavern 或刷新页面后，在扩展管理中确认“人设版本管理”已启用。

## 使用

1. 打开“用户设定管理”，选择一个已有用户人设。
2. 点击“重命名人设”右侧的图层图标，展开版本管理区域。
3. 先在“角色父级”搜索/选择一个 char；在聊天中另存版本时，默认名称为“user 名 - char 名 - 序号”，并自动绑定该 char。
4. 从右侧版本框选择版本，插件会立即应用。
5. 开启“修改时自动保存”可即时更新版本；关闭时点击“更新版本”手动保存。
6. 在“聊天绑定”中，可将已选版本绑定或重新绑定到当前聊天。
7. 已绑定聊天显示为标签，点击标签可单独解除绑定。

角色范围只负责筛选版本列表，不会在普通角色切换时强制应用版本。聊天绑定优先级更高：只有当前聊天存在明确绑定时，插件才会自动应用对应版本。

删除版本只删除插件保存的快照，不会删除 SillyTavern 原始用户人设或头像。
