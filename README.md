# SillyTavern 人设版本管理

这是一个纯前端 SillyTavern 扩展。它在“用户设定管理”的“重命名人设”按钮右侧添加版本入口，并在当前人设控制区下方展开人设版本管理区域。

## 功能

- 为同一个 SillyTavern 用户人设保存多个版本。
- 保存名称、展示标题、描述、注入位置、深度、角色和关联世界书。
- 一键应用、覆盖更新、重命名和删除版本。
- 切换版本时保留原人设的角色/群组连接。
- 数据保存在 SillyTavern 的扩展设置中，随用户设置正常保存。

## 安装

将本目录复制到：

```text
SillyTavern/public/scripts/extensions/third-party/persona-variants/
```

最终至少包含：

```text
persona-variants/
├── manifest.json
├── index.js
└── style.css
```

重启 SillyTavern 或刷新页面后，在扩展管理中确认“人设版本管理”已启用。

## 使用

1. 打开“用户设定管理”，选择一个已有用户人设。
2. 点击“重命名人设”右侧的图层图标，展开版本管理区域。
3. 编辑人设后点击“另存版本”，输入版本名。
4. 从下拉框选择版本并点击“应用”。
5. 使用“更新版本”可将当前编辑内容覆盖到已选版本。

删除版本只删除插件保存的快照，不会删除 SillyTavern 原始用户人设或头像。
